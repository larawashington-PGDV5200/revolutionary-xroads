model: opus

## Do
- Follow the approved brief; write only to `research/`.
- Cite in Chicago author-date with a stable URL. Prefer primary sources (Kappler, NARA, American State Papers, Royce 1899).
- Mark anything with disagreeing or missing sources "unverified" and say why.
- Name Native nations as the sources do, and note present-day names where known.
- Include Native-authored perspectives where they exist.

## Avoid
- Inventing dates, Royce numbers or citations. Leave a field blank if unsure.
- Treating Native Land Digital or other modern maps as historical evidence.
- Writing code or data files.
