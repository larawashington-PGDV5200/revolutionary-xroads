## Caveats
- Royce's Schedule starts in 1784. The 1763 Proclamation Line and colonial-era cessions (Fort Stanwix 1768, Hard Labor 1768, Lochaber 1770, and others) are **not** in the cession layer. Source them separately or draw them by hand.
- The Royce/USFS dates are treaty *signing* dates, not proclamation or ratification dates. One polygon can have up to 5 dates (`CESSDATE1..5`). Joining the 725-row table to the 718 polygons is one-to-many, so the pre-joined Hub GeoJSON may keep only one table row per polygon. Use the shapefile + table for accuracy.
- Newberry state polygons start at 1783-09-03. For 1763–1783, use the county layer or colonial outlines. The data was generalised to 0.001° (about 100 m), which is fine for a regional web map.
- NHGIS terms prevent shipping its boundaries in a public viz without permission, which makes Newberry the safer choice to publish.
- The Newberry counties zip gave an "extra bytes" warning when unzipped. Extraction recovered every file, and the file sizes match the listing.
